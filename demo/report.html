Table B — root causes

Every test failing in the latest build, grouped by failure signature — the error message plus the deepest frame in your own code. Tests that fail the same way in the same place are one row, so fixing one row clears every test in it. The grouping is mechanical: it tells you which tests share a cause, not why.
